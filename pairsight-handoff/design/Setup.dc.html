What should Jev compare?

Say what counts as the same, choose which values Jev gets to see, and set how sure it must be. These are the settings this demo run used.

A

What makes two records the same?

Jev reads these answers for every pair. Write them as you would explain it to a colleague.

Two records are the same when

Both records describe the same product (the same item in the same variant), even if the name, description or formatting differs.

They are different when

The records describe different products, including different variants (size, colour, capacity or edition), bundles or multipacks of the item, or similarly named products from different brands.

Records are from United Kingdom, which helps Jev read local formats for sizes, units and codes.

B

Which values Jev sees

Only ticked values are sent. Leave out anything Jev does not need, such as internal notes. It needs at least two.

Record ID (never sent)

Jev never sees what the vendors decided, so it cannot simply agree with them.
